Podrobno po pragu: dogodki, referenca, Brier Skill Score

Event rate = kolikokrat je bil dogodek dejansko izmerjen / stevilo verificiranih vzorcev.
Ref. Brier = Brier score trivialnega modela, ki vedno napove konstantno verjetnost = event rate (na istem naboru vzorcev).
BSS (Brier Skill Score) = 1 - Brier/Ref.Brier. >0 boljse od reference, 0 enako, <0 slabse, N/A ce je Ref.Brier = 0.
NO_OBSERVED_EVENTS = v tem vzorcu se dogodek ni zgodil niti enkrat - Brier tu predvsem meri, kako dobro je model napovedal odsotnost dogodka, ne njegovo prisotnost.
